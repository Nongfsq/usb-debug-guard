# Privacy Policy

USB Debug Guard is a primarily local Android utility.

- It does not collect analytics.
- It connects to `api.github.com` only when the user taps **Check updates**.
- It opens `github.com/Nongfsq/usb-debug-guard/releases/latest` only when the user chooses to view an available release.
- It does not perform automatic or background update checks.
- It does not upload logs.
- It does not store personal data.
- It stores only local preferences needed for the guard, such as the enabled state, selected mode, and saved display settings used for restore.

The app executes root commands only on the device where it is installed. Users should review the source before granting root access.

The update request contains the normal network metadata required for HTTPS, including the device IP address as observed by GitHub, plus a generic app/version User-Agent. USB Debug Guard does not add device identifiers, Root diagnostics, preferences, or logs to that request.
