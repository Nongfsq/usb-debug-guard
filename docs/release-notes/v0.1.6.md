# USB Debug Guard v0.1.6

## No network permission in the F-Droid build

The F-Droid build leaves out the in-app update check, so nothing in it uses the network. It now drops the `INTERNET` permission too, as suggested during F-Droid review. The GitHub build keeps the permission for **Check updates**. Guard behavior and Root safety are unchanged.

- Version advanced to `versionCode 7`.

## Validation

- `aapt2 dump badging`: the F-Droid APK lists no `INTERNET` permission; the GitHub APK still does.
- Two builds of the F-Droid APK from separate fresh clones are byte-identical before signing.
- API 36 emulator: the F-Droid APK installs, launches to the main screen without crashing, and the system lists no `INTERNET` grant.

## Install

Both APKs are signed with the v0.1.3+ release key and install directly over v0.1.3 or later.

- `usb-debug-guard-v0.1.6.apk`: the GitHub build, with the in-app update check.
- `usb-debug-guard-v0.1.6-fdroid.apk`: the reproducible F-Droid build, without the update check or network permission.

# USB 调试守护 v0.1.6

## F-Droid 版不再申请网络权限

F-Droid 版不包含应用内检查更新，没有任何功能会联网。应 F-Droid 审核建议，这一版连 `INTERNET` 权限也去掉了。GitHub 版仍保留该权限，供“检查更新”使用。守护功能和 Root 安全机制不变。

- 版本提升为 `versionCode 7`。

## 验证

- `aapt2 dump badging`：F-Droid 版 APK 不再列出 `INTERNET` 权限，GitHub 版仍然保留。
- 从两个独立的全新 clone 分别构建 F-Droid 版 APK，签名前逐字节一致。
- API 36 模拟器：F-Droid 版 APK 可以安装，启动到主界面没有崩溃，系统也没有授予 `INTERNET` 权限。

## 安装

两个 APK 都使用 v0.1.3 起的发布密钥签名，可以直接覆盖安装 v0.1.3 及之后的版本。

- `usb-debug-guard-v0.1.6.apk`：GitHub 版，包含应用内检查更新。
- `usb-debug-guard-v0.1.6-fdroid.apk`：可复现的 F-Droid 版，不含检查更新，也不申请网络权限。
