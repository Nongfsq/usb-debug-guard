# USB Debug Guard v0.1.2

Language and Android icon compatibility release.

## Highlights

- Adds an in-app language setting: follow system, English, or Simplified Chinese.
- Adds Android 13+ app locale integration through `locale_config`.
- Keeps a fallback locale wrapper for pre-Android 13 devices.
- Fixes the Android adaptive icon structure by separating a vector background layer from the foreground layer.
- Keeps the verified USB-C logo geometry while fitting it inside the adaptive icon safe zone.

## Build And Compatibility

- App version: `0.1.2` (`versionCode 3`)
- Package: `io.github.nongfsq.usbdebugguard`
- Built with: Android Gradle Plugin `9.2.1`, Kotlin `2.4.0`, Compose BOM `2026.05.01`
- Android SDK: `compileSdk 36`, `targetSdk 36`, `minSdk 26`
- Verified device: OnePlus CPH2723, Android 15/API 35, arm64, Linux 6.6 Android kernel

The APK remains a universal Android package. It is not split by CPU architecture or Android kernel version. Compatibility still depends mostly on the rooted Android environment: `su`, `settings`, `input`, USB/ADB reporting, SELinux policy, and OEM lock-screen behavior.

## Install

Download the APK from this release and install with:

```powershell
adb install -r usb-debug-guard-v0.1.2.apk
```

If you installed a local debug build before, Android may reject this release APK as an update because debug and release builds use different signing keys. In that case, uninstall the debug build first or keep using `tools/install.ps1` for local debug builds.

## Verification

- Android badging shows `versionName=0.1.2`, `versionCode=3`, `minSdk=26`, `targetSdk=36`.
- Device install verified on the connected Android 15 test phone.
- Privacy scan confirms no local paths, personal identifiers, credentials, signing keys, or old package names are committed.

# USB 调试守护 v0.1.2

语言设置和 Android 图标兼容性版本。

## 重点

- 新增应用内语言设置：跟随系统、English、简体中文。
- 通过 `locale_config` 接入 Android 13+ 应用语言能力。
- 为 Android 13 以下设备保留本地化 context fallback。
- 修复 Android adaptive icon 架构，将 vector 背景层和前景层分离。
- 保留已验证的 USB-C logo 几何，同时放入 adaptive icon 安全区。

## 构建与兼容性

- App 版本：`0.1.2` (`versionCode 3`)
- 包名：`io.github.nongfsq.usbdebugguard`
- 构建工具：Android Gradle Plugin `9.2.1`，Kotlin `2.4.0`，Compose BOM `2026.05.01`
- Android SDK：`compileSdk 36`，`targetSdk 36`，`minSdk 26`
- 已验证设备：OnePlus CPH2723，Android 15/API 35，arm64，Linux 6.6 Android 内核

APK 仍然按通用 Android 包发布，不按 CPU 架构或 Android 内核版本拆分。兼容性仍主要取决于已 root 的 Android 环境：`su`、`settings`、`input`、USB/ADB 状态上报、SELinux 策略和 OEM 锁屏行为。

## 安装

下载本 release 的 APK 后运行：

```powershell
adb install -r usb-debug-guard-v0.1.2.apk
```

如果设备上之前安装过本地 debug 构建，Android 可能会因为 debug 和 release 签名不同而拒绝覆盖安装。遇到这种情况请先卸载 debug 版本，或者继续使用 `tools/install.ps1` 安装本地 debug 构建。
