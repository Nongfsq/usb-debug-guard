# USB Debug Guard v0.1.5

## Smaller APK

Release builds now use R8 code and resource shrinking, as requested during F-Droid review. The APK drops from about 12.6 MB to 1.1 MB. Guard behavior and Root safety are unchanged.

- Version advanced to `versionCode 6`.

## Validation

- Local JVM/static regression script and Android lint (0 errors).
- API 35 emulator instrumentation: 4 tests.
- R8 release builds tested on an emulator. The UI loads, the foreground service starts, a Root request that is denied opens the safety circuit without crashing, and the GitHub build's **Check updates** still reaches GitHub Releases.

## Install

Both APKs are signed with the v0.1.3+ release key and install directly over v0.1.3 or v0.1.4.

- `usb-debug-guard-v0.1.5.apk`: the GitHub build, with the in-app update check.
- `usb-debug-guard-v0.1.5-fdroid.apk`: the reproducible F-Droid build, without the update check.

# USB 调试守护 v0.1.5

## 更小的 APK

应 F-Droid 审核要求，正式版改用 R8 压缩代码和资源，APK 从约 12.6 MB 降到 1.1 MB。守护功能和 Root 安全机制不变。

- 版本提升为 `versionCode 6`。

## 验证

- 本地 JVM/静态回归脚本和 Android lint（0 个错误）。
- API 35 模拟器 instrumentation：4 项测试。
- 在模拟器上测试了 R8 压缩后的正式版：界面正常加载，前台服务正常启动；Root 请求被拒绝后安全熔断正常开启，没有崩溃；GitHub 版的“检查更新”仍能访问 GitHub Releases。

## 安装

两个 APK 都使用 v0.1.3 起的发布密钥签名，可以直接覆盖安装 v0.1.3 或 v0.1.4。

- `usb-debug-guard-v0.1.5.apk`：GitHub 版，包含应用内检查更新。
- `usb-debug-guard-v0.1.5-fdroid.apk`：可复现的 F-Droid 版，不含检查更新。
