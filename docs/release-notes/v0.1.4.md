# USB Debug Guard v0.1.4

## F-Droid release

This release prepares USB Debug Guard for F-Droid. Guard behavior and Root safety are unchanged from v0.1.3.

- Adds F-Droid store metadata in English and Simplified Chinese.
- Adds the `-PupdateCheck=false` Gradle property. F-Droid builds use it to hide the in-app update check, because F-Droid delivers updates itself.
- APKs no longer embed Google's encrypted dependency metadata block.
- README shows the logo and an F-Droid badge.
- Version advanced to `versionCode 5`.

## Install

Both APKs are signed with the v0.1.3+ release key documented in `docs/RELEASE.md`, so v0.1.4 installs directly over v0.1.3.

- `usb-debug-guard-v0.1.4.apk`: the GitHub build, with the in-app update check.
- `usb-debug-guard-v0.1.4-fdroid.apk`: the reproducible F-Droid build, without the update check. F-Droid verifies that its own build matches this file and then publishes it with this signature, so F-Droid and GitHub builds can update each other.

# USB 调试守护 v0.1.4

## F-Droid 上架版本

本版本为上架 F-Droid 做准备，守护功能和 Root 安全机制与 v0.1.3 相同。

- 新增 F-Droid 商店资料，支持英文和简体中文。
- 新增 `-PupdateCheck=false` Gradle 属性。F-Droid 构建会用它隐藏应用内检查更新，因为 F-Droid 自己负责推送更新。
- APK 不再包含 Google 的加密依赖信息块。
- README 显示 logo 和 F-Droid 图标。
- 版本提升为 `versionCode 5`。

## 安装

两个 APK 都使用 `docs/RELEASE.md` 记录的 v0.1.3 起的发布密钥签名，可以直接覆盖安装 v0.1.3。

- `usb-debug-guard-v0.1.4.apk`：GitHub 版，包含应用内检查更新。
- `usb-debug-guard-v0.1.4-fdroid.apk`：可复现的 F-Droid 版，不含检查更新。F-Droid 会确认自己构建的结果与此文件一致，然后直接发布带本签名的这个文件，因此 F-Droid 版和 GitHub 版可以互相覆盖更新。
