# USB Debug Guard v0.1.4

## F-Droid release

This release prepares USB Debug Guard for F-Droid. Guard behavior and Root safety are unchanged from v0.1.3.

- Adds F-Droid store metadata in English and Simplified Chinese.
- Adds the `-PupdateCheck=false` Gradle property. F-Droid builds use it to hide the in-app update check, because F-Droid delivers updates itself.
- APKs no longer embed Google's encrypted dependency metadata block.
- README shows the logo and an F-Droid badge.
- Version advanced to `versionCode 5`.

## Install

GitHub APKs are signed with the v0.1.3+ release key documented in `docs/RELEASE.md`, so v0.1.4 installs directly over v0.1.3. The F-Droid build is signed by F-Droid. Android cannot update a GitHub build with an F-Droid build, or the reverse. To switch, disable the guard, confirm the display settings are restored, and uninstall first.

# USB 调试守护 v0.1.4

## F-Droid 上架版本

本版本为上架 F-Droid 做准备，守护功能和 Root 安全机制与 v0.1.3 相同。

- 新增 F-Droid 商店资料，支持英文和简体中文。
- 新增 `-PupdateCheck=false` Gradle 属性。F-Droid 构建会用它隐藏应用内检查更新，因为 F-Droid 自己负责推送更新。
- APK 不再包含 Google 的加密依赖信息块。
- README 显示 logo 和 F-Droid 图标。
- 版本提升为 `versionCode 5`。

## 安装

GitHub 版 APK 使用 `docs/RELEASE.md` 记录的 v0.1.3 起的发布密钥签名，可以直接覆盖安装 v0.1.3。F-Droid 版由 F-Droid 签名。Android 不能用 GitHub 版覆盖 F-Droid 版，反过来也不行；如需切换，请先关闭守护、确认显示设置已恢复，再卸载。
