# USB Debug Guard v0.1.0

Initial open-source release of USB Debug Guard.

## Highlights

- Root-only Android guard for long USB debugging sessions.
- Default behavior turns the screen off while keeping ADB reachable.
- Optional dim-awake fallback for devices that need the display awake.
- Material 3 interface with English and Simplified Chinese strings.
- Original SVG logo, Android adaptive launcher icon, and monochrome notification icon.
- No Device Admin, no network permission, no analytics, no uploaded logs.

## Build And Compatibility

- App version: `0.1.0` (`versionCode 1`)
- Package: `io.github.nongfsq.usbdebugguard`
- Built with: Android Gradle Plugin `9.2.1`, Kotlin `2.4.0`, Compose BOM `2026.05.01`
- Android SDK: `compileSdk 36`, `targetSdk 36`, `minSdk 26`
- Verified device: OnePlus CPH2723, Android 15/API 35, arm64, Linux 6.6 Android kernel

The APK is intended as a universal Android package. It is not released separately for different CPU architectures or Android kernels. Compatibility depends mainly on the rooted Android environment: `su`, `settings`, `input`, USB/ADB reporting, SELinux policy, and OEM lock-screen behavior.

## Install

Download the APK from this release and install with:

```powershell
adb install -r usb-debug-guard-v0.1.0.apk
```

Then open USB Debug Guard on the device, grant root when prompted, and enable the guard.

If you installed a local debug build before, Android may reject this release APK as an update because debug and release builds use different signing keys. In that case, uninstall the debug build first or keep using `tools/install.ps1` for local debug builds.

## Verification

- Debug and release Gradle builds pass.
- APK signature verification passes.
- Manifest/source check confirms no Device Admin usage.
- Privacy scan confirms no local paths, personal identifiers, credentials, signing keys, or old package names are committed.

# USB 调试守护 v0.1.0

USB 调试守护的首个开源版本。

## 重点

- 面向长时间 USB 调试的 root-only Android 守护工具。
- 默认行为是在保持 ADB 可访问的同时关闭屏幕。
- 提供低亮常亮备用模式，适配必须保持显示唤醒的设备。
- Material 3 界面，支持英文和简体中文。
- 原创 SVG logo、Android 自适应启动图标、单色通知图标。
- 不使用设备管理器，不申请联网权限，不收集统计，不上传日志。

## 构建与兼容性

- App 版本：`0.1.0` (`versionCode 1`)
- 包名：`io.github.nongfsq.usbdebugguard`
- 构建工具：Android Gradle Plugin `9.2.1`，Kotlin `2.4.0`，Compose BOM `2026.05.01`
- Android SDK：`compileSdk 36`，`targetSdk 36`，`minSdk 26`
- 已验证设备：OnePlus CPH2723，Android 15/API 35，arm64，Linux 6.6 Android 内核

APK 按通用 Android 包发布，不按不同 CPU 架构或 Android 内核拆分。兼容性主要取决于已 root 的 Android 环境：`su`、`settings`、`input`、USB/ADB 状态上报、SELinux 策略和 OEM 锁屏行为。

## 安装

下载本 release 的 APK 后运行：

```powershell
adb install -r usb-debug-guard-v0.1.0.apk
```

然后在设备上打开 USB 调试守护，授予 root 权限并启用守护。

如果设备上之前安装过本地 debug 构建，Android 可能会因为 debug 和 release 签名不同而拒绝覆盖安装。遇到这种情况请先卸载 debug 版本，或者继续使用 `tools/install.ps1` 安装本地 debug 构建。

## 验证

- Gradle debug 和 release 构建通过。
- APK 签名验证通过。
- Manifest 和源码检查确认没有使用设备管理器。
- 隐私扫描确认没有提交本机路径、个人标识、凭据、签名密钥或旧包名。
