# Brand Assets

The canonical mark is `logo.svg`. Android launcher and notification assets are derived from the same geometry.

- `logo.svg`: square primary mark for README and GitHub use.
- `logo-lockup.svg`: horizontal lockup for documentation headers.
- `social-preview.svg`: GitHub social preview source.
- `logo-512.png` and `social-preview.png`: generated raster exports for platforms that do not render SVG.

The logo is an original geometric mark, not a third-party icon. It combines a USB-C port, a white data rail, and a red guard indicator.
